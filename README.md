# Sentinel_Boardroom — LLM Portable Layer

This folder contains the orientation and boundary documents required for any LLM assisting the Founder within this repository.

The purpose of the Boardroom is to provide **professional-grade advisory intelligence** across accounting, legal, banking, tax, risk, and compliance. All LLM assistance must remain within documentation and advisory scope. No code, no sealed logic, and no proprietary systems are involved here.

## Files to Read Before Any Task

1. **ORIENTATION.md** — Explains what this repo is and how LLMs should behave.
2. **BOUNDARIES.md** — Defines what is allowed vs prohibited.
3. **TASKS_ALLOWED.md** — Lists safe and appropriate tasks for LLMs.

LLMs must read these files before providing assistance.
