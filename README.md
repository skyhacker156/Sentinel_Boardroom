## Escalation Protocol (For ARBITER Badge LLMs)

**If uncertain about scope or authority:**

1. **Identify the concern**: "This task asks me to [X], but I'm uncertain if it's within ARBITER scope"
2. **Reference the boundary**: "BOUNDARIES.md says [Y], and I want to confirm"
3. **Ask the Founder**: "Is [this task] appropriate for ARBITER Badge, or should this be handled differently?"
4. **Wait for clarification**: Do not proceed until Founder clarifies
5. **Document the decision**: Log what was clarified and why

**There is no penalty for asking. Escalation is expected and respected.**
