Phase_1_Vendor_Shopping_Cart_Reporting_Criteria.md

Documentation-Only Criteria Matrix • Finance/Compliance • Version: 1.0

Purpose

This document defines the Phase 1 criteria used to determine whether a vendor qualifies for inclusion in the corporate shopping cart for credit-building reporting.
It is documentation-only and non-executing.

Scope

Conceptual review criteria

High-level reporting filters

Non-specific to any vendor, bureau, or transaction

Public-safe; requires Founder approval before use

1. Qualification Matrix (Binary Criteria)
Criterion	Description	Requirement	Pass/Fail
Reports to a recognized commercial bureau	Vendor must report payment activity to at least one business credit bureau (e.g., Paydex, Intelliscore, SBFE).	Mandatory	□ Pass / □ Fail
Net terms structure	Vendor must offer structured payment terms (e.g., Net 30) enabling measurable payment behavior.	Mandatory	□ Pass / □ Fail
Positive-history potential	Vendor relationship must create recurring, reportable, on-time payments.	Mandatory	□ Pass / □ Fail
Non-personal spend	All purchases must be business-aligned and never tied to personal credit profiles.	Mandatory	□ Pass / □ Fail
Low utilization impact	Vendor spend must support stable utilization (not high-risk or volatile categories).	Mandatory	□ Pass / □ Fail
Documentable invoices	Vendor must provide itemized invoices suitable for accounting and audit trails.	Mandatory	□ Pass / □ Fail
Founder-approved use case	Vendor’s goods/services must align with operational needs for Phase 1 credit building.	Mandatory	□ Pass / □ Fail
2. Exclusion Matrix (Filters That Auto-Fail a Vendor)
Exclusion Filter	Description	Result
No bureau reporting	Vendor does not report payment activity.	Exclude
Cash-only or debit-only	No reportable credit-line behavior.	Exclude
Personal credit required	Vendor requires a personal SSN or credit pull.	Exclude
Unverifiable invoices	No documentation suitable for accounting or compliance.	Exclude
Non-business-aligned goods	Does not support credit-building categories.	Exclude
3. Reporting Readiness Indicators

A vendor that passes Phase 1 criteria should meet the following readiness indicators:

Provides consistent monthly reporting cadence

Issues clear statements or invoices

Supports on-time payment history tracking

Contributes to early-stage corporate credit maturity

Fits into the Sentinel Boardroom financial heartbeat framework

4. Decision Output (for internal documentation only)
Phase 1 Decision:
□ Include vendor in credit-building shopping cart
□ Exclude vendor pending further evaluation
□ Hold for Phase 2 review

5. Notes

This file documents criteria only.

No vendor names, addresses, or purchasing instructions should be added at this stage.

All final decisions require Founder approval.
